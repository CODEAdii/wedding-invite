# Your photos

Drop your couple / wedding photos in this folder and they will appear on the
**Our moments** card automatically — no code changes needed.

- **Formats:** `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`
- **Order:** sorted by file name, so use `01.jpg`, `02.jpg`, `03.jpg` …
- **Recommended:** portrait or square, about 1200 px wide, under ~500 KB each
- **Cropping:** the gallery shows a 4:5 portrait crop, so keep faces centred

Vite picks the photos up when you save (dev) and includes them in `pnpm build`.
